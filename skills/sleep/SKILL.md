次の作業を進めてください。作業中は利用上限の使用率を確認し、いずれかの枠が 95% に達したら、リセットまで待ってから再開してください。 $ARGUMENTS

## 使用率の確認

- Codex: この SKILL.md と同じディレクトリの `usage.sh codex`
- Claude Code デスクトップアプリ: `mcp__ccd_session_mgmt__get_usage`（遅延読み込みなら ToolSearch で読み込む）
- Claude Code（CLI）: `usage.sh claude`。`claude -p` を1回呼ぶので、少し使用量を使う
- 読めなければユーザーに伝え、待つ時刻を指定してもらう

作業を始める前と、作業の区切りごとに確認する。区切りがなくても30回程度、85% 以上なら10回程度のツール呼び出しごとに確認し、増え方が速ければ間隔を縮める。
確認のためだけのツール呼び出しは増やさず、`usage.sh` はほかのシェルコマンドの後ろにつなげて実行する。

## 待ち方

きりのよいところで止め、どの枠が何 % か、何時まで待つか、再開後に何をするかをユーザーに伝えてから待つ。
複数の枠が 95% 以上なら、リセットが最も遅い枠に合わせる。待つ時刻にはリセット時刻から60秒ほど余裕を足す。

- Claude Code: Bash ツールに `run_in_background: true` を付けて `sleep <秒数>` を実行し、ターンを終える。終わると呼び戻される
- Codex: シェルで `sleep <秒数>` を実行し、実行中のまま制御が戻ってきたら出力待ちを最長にして待ち続ける

待っている間はほかのツール呼び出しをしない。
戻ってきたら `date` と使用率を確認し、まだなら待ち直す。依頼された作業が終わるまで、これを繰り返す。
