ユーザーが指定した時刻まで待ってから、中断していた作業を再開してください。 $ARGUMENTS

このスキルは、トークンの利用上限に達しそうなときに、上限がリセットされて再び使えるようになるまで待つために使います。
指定時刻はたいてい上限のリセット時刻なので、待っている間はトークンをできるだけ使わないようにしてください。

- `date` で現在時刻を確認し、指定時刻までの秒数を計算する。日付の指定がなく、その時刻が今日すでに過ぎていれば翌日の時刻とする
- 待つ前に、何時まで待つかと、再開後に何をするかを1文でユーザーに伝える
- 待ち方
  - Claude Code の場合: Bash ツールに `run_in_background: true` を付けて `sleep <秒数>` を実行し、そのままターンを終える。sleep が終わると呼び戻される（フォアグラウンドの sleep は使わない）
  - Codex の場合: シェルで `sleep <秒数>` を実行する。実行中のまま制御が戻ってきたら、出力待ちを最長にして待ち続ける
- 待っている間は、ほかの作業や不要なツール呼び出しをしない
- 制御が戻ってきたら `date` で指定時刻を過ぎたか確認する。まだ前なら（タイムアウトで止まった場合も含め）残りの秒数で同じように待ち直す
- 指定時刻を過ぎたら、待つ前に伝えた作業から再開する
